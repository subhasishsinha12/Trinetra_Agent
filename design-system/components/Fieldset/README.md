# Fieldset

Fieldset groups related intake fields under an `h3` legend: "Identity and dates", "Loss components, ₹", "Recoveries, ₹", "Evidence checklist (drives DQ score)".

**Consumer provides** `legend`, optional `description`, and Fields (two-column grid, one column under 600px) or Checkboxes (`layout="checks"`, wrapping row). Consecutive fieldsets get a hairline between them.
