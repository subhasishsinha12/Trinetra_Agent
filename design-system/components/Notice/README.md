# Notice

Notice is an inline note that qualifies the content around it: illustrative data, the append-only rule, a blocking data gap.

**Consumer provides** `tone` (`neutral` default, `warn`, `pass`, `fail`), an optional bold lead-in `title` ending with a full stop, and one or two sentences as `children`.

**Use** `warn` for anything not board-approved and `fail` for a blocking problem the user must fix. Use `neutral` for standing rules ("Corrections create a new version"). Non-neutral notices carry their glyph automatically.
