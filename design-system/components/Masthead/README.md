# Masthead

Masthead opens every Trinetra screen with the product name, its one-line scope and the provenance strip.

**Use** once per screen, at the top, directly on `paper`.

**Consumer provides**
- `title`: product name in capitals as written (`TRINETRA-RISK`).
- `version`: short version tag (`v2`). It renders in `mono` `ink-muted`.
- `children`: one sentence of scope. Name the regulation and the gate. End with what is illustrative.
- `meta`: `{label, value}` pairs for the provenance strip: ruleset, source circular, mode. Labels are short nouns. Values are verbatim references.

**Do** keep the meta strip to three to five items. **Don't** put actions or status badges in the masthead.
