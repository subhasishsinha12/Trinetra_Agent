# Badge

Badge is a short status or reference chip: a rule result, a classification, the engine mode.

**Consumer provides** `tone` and one to three words. Status tones (`pass`, `warn`, `fail`) prepend ✓ ! ✕ automatically, so the status never depends on colour alone. Set `glyph={false}` only when the word itself is the glyph. Use `mono` for codes (`OR-HYBRID`, `L1: EDPM`). Use `brand`, `measure` and `discern` for eye or ownership tags.

**Don't** put sentences in badges or make them clickable.
